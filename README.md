# Биолаб

Интерактивные модели и задания по биологии. Сайт статический: сборка не нужна, достаточно выложить эту папку на любой хостинг.

## Как устроено

```
index.html, css/        оболочка сайта
js/app.js               навигация, страницы тем, проверка заданий
js/core/                прогресс ученика, общая «сцена» для моделей
js/task-types/          типы заданий (выбор, соответствие, порядок, ввод ответа)
sims/<имя>/index.js     модели, каждая в своей папке
sims/_shared/art.js     общие рисунки: липиды, белки, молекулы
sims/_shared/glossary.js справки, которые показываются по нажатию
sims/_shared/explorer.js общий каркас моделей «строение»: части, справка, игра «найди на модели»
content/catalog.json    разделы и темы
content/<раздел>/*.json уроки: текст, модели, задания
```

## Адреса страниц

`#membrane` — тема, `#membrane-transport` — её раздел. Идентификаторы тем — латиницей, без дефисов.

## Добавить тему

1. Создать файл урока в `content/<раздел>/<тема>.json` по образцу `content/cell/membrane.json`.
2. Добавить тему в `content/catalog.json`.

## Добавить модель

1. Создать папку `sims/<имя>/` с файлом `index.js`, который экспортирует `mount(root, api)` и возвращает `{ destroy() }`.
2. Вставить в урок блок `{ "type": "sim", "sim": "<имя>" }`.

## Добавить тип задания

1. Создать файл в `js/task-types/` с функцией `create(item, host, onChange)`, возвращающей `{ ready(), check(), reset() }`.
2. Зарегистрировать его в `js/task-types/index.js`.

## Запуск на своём компьютере

```
python3 -m http.server 8000
```

и открыть http://localhost:8000
